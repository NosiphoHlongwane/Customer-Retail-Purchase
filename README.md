# Project Overview
---
Dataset Overview: This dataset records customer purchases across several product categories during the year 2023. It captures critical customer attributes like age and gender, alongside transaction details including product category, quantity purchased, and total amount spent. It is ideal for analyzing consumer behavior, identifying sales trends, and building recommendation or forecasting models.

- This Excel project showcases my data cleaning, trend analysis, and dashboard creation skills.
